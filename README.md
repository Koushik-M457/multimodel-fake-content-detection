# Multimodal Fake Content Detection

This project detects fake or misleading social media posts using 
a multimodal AI model that analyzes both images and text.

## Features
- Image + text analysis
- Fake content detection
- Real-time filtering
- Social media post classification

## Tech Stack
- Python
- TensorFlow / PyTorch
- NLP
- Computer Vision
